MQL5 Trade Classes
A collection of MQL5 classes for streamlined trading operations in MetaTrader 5.
This library wraps the standard trade functions into reusable, object-oriented components,
reducing boilerplate code and improving maintainability for Expert Advisors and scripts.

Overview
The MQL5 Standard Library provides a set of trade classes located in the Include\Trade directory . 
These classes encapsulate account, symbol, order, position, and deal information, along with trade execution logic.
Instead of calling low-level MQL5 functions directly,
you can instantiate these classes and work with properties and methods in a more intuitive way.
